# Pakus Drop v0.10 – iPhone Build Ready

Diese Version ist auf den ersten EAS/iPhone-Test vorbereitet.

## Enthalten
- komplettes Gameplay aus v0.9
- Pakus Pulse / Pakus Mode
- Hold / Next / Ghost
- Bomb / Pulse Core / Phase Spezialblöcke
- Missionen, Booster, lokaler Highscore
- Sounds, Start-Cue und Game-Over-Feedback
- App Icon + Splash
- iOS Bundle ID `com.pakus.drop`
- iOS Buildnummer 10
- EAS Preview- und Production-Profile
- Build-/App-Store-Checklisten
- Export-Compliance-Flag für keine nicht-ausgenommene Verschlüsselung gesetzt

## Wichtig
Der Shop bleibt in dieser Version Demo. Für einen internen Test ist das okay; vor einer öffentlichen App-Store-Einreichung muss er auf echte Apple-IAP umgestellt oder aus dem Review-Build entfernt werden.

Siehe `BUILD_IPHONE.md` für den nächsten Schritt.
